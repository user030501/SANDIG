Users of the System

1. Administrator

Main role:
Manages the whole system.

Prototype access:
Dashboard
User Management
PWD Profiles
Assessments
At-Risk Cases
Referrals
Reports
Audit Logs
Settings

Functions:
Add, edit, deactivate users
Assign user roles
Manage access permissions
View all records
Generate system reports
View audit logs

2. Barangay Staff

Main role:
Handles PWD registration and record updates.

Prototype access:
Dashboard
PWD Profile Management
Welfare Assessment
Reports

Functions:
Register PWD profile
Update PWD information
Encode household details
Encode caregiver details
View assessment history
Generate basic reports

3. PWD Focal Person

Main role:
Reviews PWD cases and manages referrals.

Prototype access:
Dashboard
PWD Profiles
Welfare Assessment
At-Risk Cases
Referral Tracking
Case Notes
Reports

Functions:
Review flagged cases
Confirm unmet needs
Create referral
Update referral status
Set follow-up dates
Record referral outcome

4. Barangay Health Worker or Field Worker

Main role:
Conducts field assessments and follow-ups.

Prototype access:
Mobile Case Update
PWD Profile Summary
Welfare Assessment
Case Notes
Referral Follow-Up

Functions:
Search PWD profile
Update welfare assessment
Record health concerns
Record assistive device issues
Add home visit notes
Update follow-up result

5. Barangay Official

Main role:
Views summaries for planning and monitoring.

Prototype access:
Dashboard
Reports
At-Risk Case Summary
Referral Summary

Functions:
View total registered PWDs
View at-risk cases
View pending referrals
View common unmet needs
View printable reports
